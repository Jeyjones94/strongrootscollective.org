# 🌱 Strong Roots Collective

**Website for Strong Roots Collective**  
*Grounded in strength. Growing in healing.*

---

## 🧠 Mission

To normalize mental health conversations, break stigma, and create culturally competent, accessible resources for Black men and boys across the U.S.

---

## 📍 Key Features

- Hero section highlighting the mission
- Focus areas: Awareness, Resources, Advocacy, Community
- CTA buttons for donations, involvement, and learning more
- Responsive design using React and TailwindCSS
